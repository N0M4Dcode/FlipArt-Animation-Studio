 🎨 Flipart Animation Studio

**Draw. Animate. Create.**

A modern 2D drawing and animation studio for Windows, designed to make animation accessible to beginners while providing powerful creative tools for artists, animators, and indie game developers.

Inspired by the simplicity of classic flipbook animation applications, **Flipart Animation Studio** brings traditional frame-by-frame animation into a modern desktop environment.

Create animations, refine individual strokes, preview motion, and export your creations for sharing or use in other projects.

## ✨ Features

### 🖌️ Drawing Studio

- Freehand drawing with mouse, pen, or compatible drawing tablet.
- Customisable brushes, colours, and drawing tools.
- Editable strokes for precise adjustments.
- Spline-based editing for refining existing lines and curves.
- Independent drawing frames, allowing changes without affecting previous artwork.
- Clean, distraction-free drawing environment.

### 🎞️ Frame-by-Frame Animation

- Traditional flipbook-style animation workflow.
- Create, duplicate, edit, and remove individual frames.
- Onion skinning to display previous and upcoming frames.
- Adjustable animation playback speed.
- Timeline-based frame navigation and editing.
- Preview animations directly inside the studio.
- Refine drawings between frames to create smooth, consistent movement.

### 🧩 Advanced Animation Tools

- Fine-tune individual lines and control points.
- Adjust existing drawings without completely redrawing them.
- Record drawing strokes for animated line-reveal effects.
- Control how drawings appear throughout an animation.
- Maintain independent artwork across animation frames.

### 🎮 Game Development Workflow

Flipart Animation Studio is designed with indie game developers in mind.

Create 2D animations and visual assets without needing to learn the animation systems of a game engine.

Planned workflows include:

- Character animation.
- Animated sprites.
- Environmental animations.
- Visual effects.
- Sprite-sheet exports.
- Animation sequences for game engines.

### 📤 Animation Export

Export your animations for sharing, presentations, and game development.

Target export capabilities include:

- Animated GIF.
- PNG image sequences.
- Sprite sheets.
- Transparent-background assets.

Initial animation defaults:

| Setting | Default |
|---|---|
| Animation speed | 30 FPS |
| Export resolution | 1024 × 1024 |
| GIF playback | Infinite loop |
